# P106-090 原版 EFI x16 验证

## 为什么先做 P106-090

`NVPermissiveEFI-202610220846.efi` 的原版宽度事务明确支持：

```text
P106-090 / 10DE:1C09
```

不支持 P104-100 `1B87`。因此先用原版 EFI 在 P106-090 上验证 x16，
可以得到可信的成功/失败基线，再用于修正 P104 实验分支。

## 自动制作 U 盘

双击：

```text
make-p106-090-x16-usb.bat
```

输入 FAT32 U 盘盘符。BAT 会复制并校验：

```text
\EFI\BOOT\BOOTX64.EFI             UEFI Shell
\NVPermissiveEFI.efi              原版 NVPermissive EFI
\startup.nsh                      自动运行脚本
```

启动 U 盘后自动执行：

```text
NVPermissiveEFI.efi pcie-width
```

## 测试前

- 最好只保留 P106-090，移除 P104 和其它 NVIDIA 卡；
- Secure Boot 关闭；
- 使用正常 x16 电气插槽，避免 x1/x2/x4 转接线；
- EFI 上次失败后必须先完全断电，不要热重启；
- 保存完整屏幕输出。

## 日志重点

```text
GPU/RP LnkCap
GPU/RP LnkSta
BAR0[0x88150] requested/read
pcie-width: completed
pcie-width: both ends stable
```

如果 P106-090 也稳定停留在 Gen1/Gen2 x4，那么 P104 的失败更可能是
lane strap/PCB/宽度事务条件问题，而不是白名单问题。

如果 P106-090 能到 x16，则把完整日志作为 P104 对照，用它定位 P104
缺少的寄存器回写、桥端预置或重训步骤。

## 电容齐全但仍然 x4

即使 PCIe 金手指附近的 AC 耦合电容都焊满了，也不能保证链路训练到 x16。
电容只解决“电气通路存在”这一项。PCIe 最终宽度还要同时满足：

1. 端点自己声明最大 x16，也就是 `LNKCAP.MAXWIDTH == 16`；
2. GPU 的 lane strap / PCIe 核没有被配置成 x4；
3. PCB 上 lane 4-15 的走线、金手指触点和回流路径完整；
4. 主板插槽没有 bifurcation 成 `x4x4x4x4`，也没有经过 x4 延长线；
5. 上游根端口最大 x16；
6. 链路训练期间没有 lane reversal、信号完整性问题或热插拔检测异常。

本机 P106-090 的初始探针值是：

```text
LNKCAP = 0x00453C41
MAXWIDTH = (LNKCAP >> 4) & 0x3F = 4
```

也就是说，这张卡在软件读取到的能力表里，自己声明最大只有 x4。`LNKCAP`
是只读能力寄存器，`pcie-width` 和 `pcie-gen2-x16` 能写 BAR0 的宽度事务，
但不能改写端点已经锁存的 `LNKCAP.MAXWIDTH`。这种情况下链路训练结果不会
超过 x4。

如果同一张卡后来读到的 `LNKCAP` 已经变成最大 x16，但 `LNKSTA` 仍为 x4，
那么问题就从“声明/电容”转移到“物理通路或主板配置”。此时应优先检查插槽
bifurcation、是否使用转接线，以及 lane 4-15 是否真的通到金手指。

## 成功日志

```text
BOOT0=0x136000a1
XP_CONFIG=0x80049000
LINK_SPECIFIER=16
GPU/RP LnkCap=0x00453d02/0x0261ad03
GPU/RP LnkSta=0x1102/0xd102
pcie-gen2-x16: GPU Gen2 x16 (baseline Gen1 x4, target Gen2 x16)
pcie-gen2-x16: both ends stable actual Gen2 x16 (baseline Gen1 x4, core=0)
GPU 0000:01:00.0 result=0x0
```

解码：

```text
GPU  LnkSta = 0x1102  ->  Gen2 x16
RP   LnkSta = 0xd102  ->  Gen2 x16
result      = 0x0      -> 成功
```

这是 P106-090 原版 `pcie-gen2-x16` 的实测成功结果。它证明宽度事务对
`10DE:1C09` 可以工作，后续 P104 `1B87` 的补丁应以此寄存器路径为对照。
