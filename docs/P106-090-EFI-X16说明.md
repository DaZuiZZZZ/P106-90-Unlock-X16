# P106-090 EFI x16 宽度验证

## 目标

本项目只验证 P106-090 / `10DE:1C09` 的 PCIe 链路宽度：

```text
默认 x4 -> 目标 x16
```

不把 Gen2 / Gen3 速率提升作为独立功能。

## 原版 EFI

`NVPermissiveEFI-202610220846.efi` 的原版宽度事务支持：

```text
P106-090 / 10DE:1C09
```

执行命令：

```text
NVPermissiveEFI.efi pcie-gen2-x16
```

`pcie-gen2-x16` 是 NVPermissive 二进制自带的模式名。项目目标是 x16 宽度，
命令名中的 `gen2` 不代表项目承诺 Gen2 速率。

## 成功判据

看端点与根端口的 `LnkSta` 宽度字段，而不是只看命令是否返回：

```text
GPU LnkSta WIDTH = 16
RP  LnkSta WIDTH = 16
```

本机成功示例：

```text
GPU LnkCap = 0x00453d02  -> MAXWIDTH = 16
GPU LnkSta = 0x1102      -> WIDTH = 16
RP  LnkCap = 0x0261ad03  -> MAXWIDTH = 16
RP  LnkSta = 0xd102      -> WIDTH = 16
```

GPU-Z 的 `Bus Interface` 应同时显示：

```text
PCIe x16 ... @ x16 ...
```

## 失败时

如果仍然显示 `@ x4`，检查：

- `LNKCAP.MAXWIDTH` 是否真的是 16；
- PCB lane 4-15 是否完整；
- AC 耦合电容和端接是否齐全；
- 主板插槽是否被 bifurcation 成 `x4x4x4x4`；
- 是否经过 x4 延长线或转接板；
- 根端口是否支持 x16。

EFI 只能执行寄存器宽度事务，不能补出物理上不存在的 lane。
